## 📊 **Tag Hierarchy & Cross-Reference System**

### 🎯 **PRIMARY CLASSIFICATION TAGS**

#### **Concept Categories** `#concept/[topic]`
```
#concept/variables          - Variable declaration, assignment, naming
#concept/data-types         - int, float, string, boolean fundamentals  
#concept/input-output       - input(), print(), formatting
#concept/operators          - Arithmetic, comparison, logical operators
#concept/control-flow       - if/elif/else conditional statements
#concept/loops              - for loops, while loops, iteration
#concept/functions          - Function definition, parameters, return
#concept/data-structures    - Lists, dictionaries, tuples, sets
#concept/strings            - String manipulation, methods, formatting
#concept/file-handling      - File I/O, reading, writing, exceptions
#concept/error-handling     - try/except, validation, debugging
#concept/modules            - import statements, standard libraries
```

#### **Source Classification** `#source/[type]`
```
#source/in-class           - From daily class folders
#source/book               - From Gaddis textbook

```

## 📋 **TAGGING WORKFLOW**

### **Standard Tagging Pattern**
1. **Primary Concept**: `#concept/[main-topic]`
2. **Source**: `#source/[where-from]` 
3. **Difficulty**: `#difficulty/[level]`
4. **Exam Relevance**: `#exam/[priority]`
5. **Professor Style**: `#prof-style/[aspect]` (if applicable)
6. **Date/Chapter**: `#date/[MMDD]` or `#book/[chapter]`

### **Example Complete Tagging**
```
Tags: #concept/input-output #source/in-class #difficulty/beginner 
      #exam/critical #prof-style/validation #date/1020 #code/snippet
```
