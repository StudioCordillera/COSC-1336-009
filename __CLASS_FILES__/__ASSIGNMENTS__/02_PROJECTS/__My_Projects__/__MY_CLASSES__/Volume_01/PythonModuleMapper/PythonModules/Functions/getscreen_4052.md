# Function: getscreen()

## Overview

Return the TurtleScreen object, the turtle is drawing  on.

No argument.

Return the TurtleScreen object, the turtle is drawing  on.
So TurtleScreen-methods can be called for that object.

Example (for a Turtle instance named turtle):
>>> ts = turtle.getscreen()
>>> ts
<turtle.TurtleScreen object at 0x0106B770>
>>> ts.bgcolor("pink")
