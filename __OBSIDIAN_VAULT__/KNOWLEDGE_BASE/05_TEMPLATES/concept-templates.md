## 🏷️ **Tag Reference Guide**

### Primary Tags
- `#concept/[topic]` - Core programming concepts
- `#prof-style` - Professor's preferred approaches
- `#book-ref/ch[X]` - Textbook chapter references
- `#exam-critical` - High-probability exam content
- `#code-snippet` - Reusable code examples
- `#pattern/[type]` - Common programming patterns

### Secondary Tags
- `#difficulty/[level]` - Complexity indicators
- `#date/[class-date]` - When concept was covered
- `#project/[name]` - Associated project connections
- `#syntax/[style]` - Specific syntax patterns
- `#error/[type]` - Common error patterns and fixes

### Topic Categories
- `#concept/variables` - Variable declaration and usage
- `#concept/control-flow` - If/else, loops, etc.
- `#concept/functions` - Function definition and calls
- `#concept/data-structures` - Lists, dictionaries, etc.
- `#concept/input-output` - User interaction patterns
- `#concept/file-handling` - File operations
- `#concept/error-handling` - Exception management
