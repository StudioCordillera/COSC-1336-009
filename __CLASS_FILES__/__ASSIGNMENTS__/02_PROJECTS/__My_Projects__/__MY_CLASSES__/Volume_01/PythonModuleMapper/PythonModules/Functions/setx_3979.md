# Function: setx()

## Overview

Set the turtle's first coordinate to x

Argument:
x -- a number (integer or float)

Set the turtle's first coordinate to x, leave second coordinate
unchanged.

Example (for a Turtle instance named turtle):
>>> turtle.position()
(0.00, 240.00)
>>> turtle.setx(10)
>>> turtle.position()
(10.00, 240.00)
