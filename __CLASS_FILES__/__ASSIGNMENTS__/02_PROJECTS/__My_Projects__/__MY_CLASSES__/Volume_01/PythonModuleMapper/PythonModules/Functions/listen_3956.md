# Function: listen()

## Overview

Set focus on TurtleScreen (in order to collect key-events)

No arguments.
Dummy arguments are provided in order
to be able to pass listen to the onclick method.

Example (for a TurtleScreen instance named screen):
>>> screen.listen()
