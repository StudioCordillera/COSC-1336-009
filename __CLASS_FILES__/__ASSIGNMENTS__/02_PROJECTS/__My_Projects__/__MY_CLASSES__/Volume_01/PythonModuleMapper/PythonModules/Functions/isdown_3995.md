# Function: isdown()

## Overview

Return True if pen is down, False if it's up.

No argument.

Example (for a Turtle instance named turtle):
>>> turtle.penup()
>>> turtle.isdown()
False
>>> turtle.pendown()
>>> turtle.isdown()
True
